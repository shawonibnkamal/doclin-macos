## An early source preview

Doclin focuses on local processing and a simple Mac workflow. We have not
established better accuracy than Wispr Flow. Names, corrections, and insertion
into some editors still need work. Review important numbers and meaning.

**Signed and notarized app downloads are not available yet.** You can build the
source now. Rebuilding an ad-hoc preview can require macOS permission renewal.
